# Bootstrap példák

Ez a projekt bemutatja a Bootstrap 5 alapvető komponenseinek használatát egyszerű HTML példákon keresztül.

## Fájlok

- **card.html** – Kártya komponens, termékek megjelenítésére
- **carousel.html** – Carousel (képgaléria) komponens, lapos képekkel
- **button.html** – Különböző Bootstrap gombok, gombcsoportok keretben

## Használat

1. Nyisd meg a kívánt HTML fájlt böngészőben.
2. Minden példa CDN-en keresztül tölti be a Bootstrap CSS-t és (ha kell) a JS-t.
3. A példák alapvetően reszponzívak, de mobilon nem minden esetben tökéletes, hogy a kód minél átláthatóbb maradhasson és jobban szemléltesse a lényeget.

## Bootstrap dokumentáció

- [Bootstrap 5.3.8](https://getbootstrap.com/docs/5.3/)
